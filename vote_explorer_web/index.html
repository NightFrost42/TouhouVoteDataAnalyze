口径与部署

      
研究型网络仅读取离线统计结果，运行参数和完整性见图下注释与清单。普通视图读取仓库内的全量分析 CSV；实体问卷、角色/曲子交叉、CP、同投矩阵、网络、气泡、指标、跨届变化、方向、累计、聚类、四象限、异常和自定义视图先按当前筛选计算，再按 Top N 切片。空白不等于 0。中文区和日文区的同人曲投票窗口使用各自的日期。

      
部署到 GitHub Pages 时，默认数据路径为 ../vote_explorer/data/。如果只发布本目录，可在 URL 后追加 ?data=./data/ 并把所需 CSV 放入同名 data 目录。
