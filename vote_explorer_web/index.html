口径与部署

网页读取仓库内的全量分析 CSV；实体问卷、角色/曲子交叉、CP、同投矩阵、网络、气泡、指标、跨届变化、方向、累计、聚类、四象限、异常和自定义视图均先按当前筛选重算全量数据，再在最后一步按 Top N 切片。空白表示原始来源未公开，不会强制填成 0。中文区和日文区的同人曲投票窗口使用各自的日期。

部署到 GitHub Pages 时，默认数据路径为 ../vote_explorer/data/。如果只发布本目录，可在 URL 后追加 ?data=./data/ 并把所需 CSV 放入同名 data 目录。
