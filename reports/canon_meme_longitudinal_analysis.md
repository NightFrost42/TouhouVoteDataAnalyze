# 一设—梗/二创—社媒—投票的长期对齐分析（第3—21回）

生成时间：2026-08-23（Asia/Shanghai）。本报告把官方角色设定、官方投票表、公开社交平台内容和发布时间放在同一条时间轴上。长期名次原始表为 [`metadata/vote_history_longitudinal.csv`](../metadata/vote_history_longitudinal.csv)，事件逐条证据表为 [`metadata/canon_meme_events.csv`](../metadata/canon_meme_events.csv)。

## 结论先行

1. **阿求最适合被解释为“官方设定提供素材，现实年表外推形成长期公认梗，2024节点集中放大，结果又被梗吸收”。** “御阿礼之子短命、约30岁”是一设；“2024年8月7日精确死亡”是按生日和寿命外推的社区日期。海螺小姐时空使官方剧情时间不按现实日历推进，所以不能写成“官方剧情已于2024年演到死亡”；但这不否定社区长期把“按时间算她会死”当作共同前提。第21回名次回落只说明未观察到稳定名次维持，不能进一步声称已测得或否定票数转化。
2. **第20回不是梗的起点，而是长期梗的集中事件节点。** 已登录X检索可见2016、2017、2018、2020、2021、2023和2024投票前的连续讨论；2024-08-06视频承接并放大旧梗，投票在2024-08-10开始。第20回结果中阿求由第19回86名升至39名（+47名），8月24日又出现“上升47名”视频。时间顺序支持“长期梗先存在、2024集中传播、名次后被梗化解释”，不支持“某个视频造成47名跃升”。
3. **第21回恋恋是“长期基础盘 + 结果日放大”的组合。** 恋恋第6回35名逐步进入头部，第11回第一次第一，此后第12—20回一直在3—6名，第21回回到第一。F1模板、结果反应和“十年之约”视频以及日本X的“こいしちゃん”连续四个半小时Top10都发生在投票结束后，说明它们主要解释和放大了冠军的社会意义，而不是投票期因果证据。
4. **长期轨迹至少有三种模式：**（a）原作登场/自机效应后的快速上升并平台化（早苗）；（b）设定和二创长期积累形成慢变量（芙兰、琪露诺、妖梦）；（c）事件性梗带来短期峰值后回落（阿求）。因此不能把所有“高社媒可见度”视作同一种动员机制。
5. **投票分布比单一总分更重要。** 早期和近年计分规则不同，跨届不直接比较积分绝对值；优先比较名次、同届内一押/评论/支援作品、头部差距和排名分位。第21回现行3/2/1规则下恋恋27,688分、魔理沙27,553分、灵梦27,408分，前三相差仅280分；按上一回2/1权重对同一批聚合选票机械重算，前三会变成魔理沙、灵梦、恋恋。这是规则敏感性，不是刷票证明。

## 证据分层：一设不是梗，梗也不是票

| 层级 | 可以说什么 | 不可以说什么 |
|---|---|---|
| 官方一设/官方作品 | 角色的年龄、能力、身份、登场和叙事素材 | 一设本身造成了某届具体票数 |
| 官方投票结果/问卷 | 名次、积分、票型、回答者结构、支援链接数量 | 支援作品数等于动员票数 |
| 二创/梗及发布时间 | 某个叙事何时出现、如何被包装、是否在结果日前后 | 播放量等于发布日曝光，更不能换算成票 |
| 趋势网站 | 结果日是否进入地区Top10、搜索兴趣是否抬升 | 趋势估算等于完整话题总量或投票率 |

## 阿求：短命是一设，“按现实时间会死”是长期公认梗

### 设定层

阿求作为御阿礼之子转生，官方设定给出短命、约30岁的寿命叙事；同时，ZUN以“海螺小姐时空”回应她的最终命运，实际含义是作品世界不会像现实年表那样逐年推进。因此要区分三句话：

- **一设事实：**短命和转生循环是官方设定素材。
- **社区外推：**把出生日期、约30年寿命与现实日历相乘，得到“2024-08-07会死”的假设性日期。
- **官方剧情：**没有“2024-08-07死亡”的情节；海螺小姐时空使现实日期不能直接当剧情时间。

这个“设定上有寿命、剧情时间又被悬置”的张力，使寿命论、倒计时、遗照、葬礼、三途川和“复活赛”可以同时成立。社区对精确日期的认真程度有分歧，但“按现实时间推算会死”本身远早于2024视频，已经是可被直接调用的共同梗。

### 投票和社媒的时间顺序

| 时间 | 事件 | 读法 |
|---|---|---|
| 2016—2023 | X连续出现“若非海螺小姐时空不久会死”“再出约五作会死”“2024前后是转折点”等讨论 | 证明现实年表死亡梗长期存在，并非投票前临时建构 |
| 2024-08-06 | B站 `BV1sSareYEQj` 发布“稗田阿求于2024.8.7安详逝世” | 投票开始前承接并放大长期梗；当前约24.2万播放只是累计快照 |
| 2024-08-07 | “赛博喜丧”在B站、X、微博及P图/葬礼二创中扩散；媒体报道B站热搜第三 | 一设被转译成事件性社群话题；精确死亡日仍是粉丝推算 |
| 2024-08-10—08-23 | 第20回投票 | 没有个体级曝光—投票链，不能识别梗带来的新增票 |
| 2024-08-24 | 阿求第20回39名公布；B站 `BV1EpWZe2EvU` 发布“上升47名”梗视频 | 名次变化被既有梗快速吸收，属于赛后解释/再叙事 |
| 2025-08-29后 | 第21回阿求79名 | 比第20回回落40名，构成短期可见性未变成稳定投票盘的反例 |

因此最稳妥的句子是：**官方短命设定长期支持“现实年表会死”的社区外推；2024节点让旧梗集中传播，并为赛后名次提供解释框架。第20回+47名与第21回−40名说明事件峰值没有表现为稳定名次维持，但现有材料仍不能估计梗带来的票数。**

## 恋恋：原作符号的慢变量，结果日梗的快变量

恋恋名次为：第6回35 → 第7回22 → 第8回15 → 第9回14 → 第10回3 → 第11回1 → 第12—16回3—4 → 第17回4 → 第18回6 → 第19回4 → 第20回4 → 第21回1。这个序列先于2025年赛后视频，说明冠军不能只用结果日的F1梗或“十年之约”解释。

官方设定中的闭合第三只眼、无意识行动和地灵殿关系，为“无意识/读心/恋恋”二创提供长期识别符号。第21回结果日16:30—18:03，B站连续出现F1模板、东方厨反应模板和“十年后回到第一”短片；日本X归档在JST 17:00—18:30连续四个半小时出现“こいしちゃん”Top10，估算推文约1.866千升至4.008千。Google Trends却显示日本区“古明地こいし”从投票周67降到结果周60，而“東方Project人気投票”从14升至27：**搜索词、X趋势和B站二创测到的是不同层次的注意力。**

此外，第21回现行3/2/1计分下恋恋只比魔理沙高135分、比灵梦高280分；旧2/1权重反事实则改为魔理沙、灵梦、恋恋。社区“十年后第一”的叙事是真实存在的结果后叙事，但不能倒推为投票期动员或单一二创的原因。

## 投票分布与社群旁证如何合并

### 第20回

- 灵梦第1名21,959分、官方支援数57；魔理沙第2名20,249分；芙兰第3名17,324分；恋恋第4名16,273分，头部存在明显梯度。
- 阿求3,011分、315个一押、822条评论、6条支援，名次39。她的名次跃升很大，但仍不是头部支援供给或票型规模；更像“中位段的显著波动 + 社区叙事放大”。
- 结果日X归档记录“霊夢1位”进入日本Top10（约1.821千推文估算），B站结果搬运和阿求47名梗同日发布，说明赛后传播把多个角色结果重新包装成可分享内容。

### 第21回

- 恋恋27,688、魔理沙27,553、灵梦27,408，前三只差280分；芙兰23,917形成第二层。恋恋一押5,133，魔理沙3,777，灵梦3,618；规则权重对前三标题有实质影响。
- 恋恋、魔理沙、灵梦的19岁及以下详情回答比例分别为68.46%、65.15%、59.51%，首次参投比例为43.13%、44.84%、42.46%。前三共同偏年轻且新参较多，不能把恋恋夺冠简化为“某平台新人独占动员”。
- 官方第22回支援页（当前）可见434条原创支援作品，约254条链接到X、109条到Pixiv，插画约377条，另有视频、音乐、漫画、SS。它证明投票网站把二创纳入应援基础设施，但没有点击、曝光或投票ID联结，不能当作票数代理。

## “历史上有没有网站统计趋势？”

- [Twitter Trending Archive](https://archive.twitter-trending.com/)：可按国家和日期读半小时Top10及推文估算，适合验证结果日是否进入区域趋势榜，不适合完整话题量。
- [Google Trends](https://trends.google.com/trends/explore)：可回溯周级0—100搜索兴趣；不同词、不同窗口不能当绝对量比较。
- [GetDayTrends 日本](https://getdaytrends.com/japan/)：理论上可提供历史小时Top50，本次访问返回Cloudflare 520，因此未把不可复核页面混入数表。
- [Trends24](https://trends24.in/)：适合实时/24小时趋势，长期归档与导出范围有限。
- [BiliOB/ZeroRoku](https://zeroroku.com/bilibili)：可观察UP主榜，但没有公开旧视频逐日曲线；本项目只保存发布时间和当前累计快照。

## 可以下的结论与不能下的结论

### 可以下

- 一设为梗提供了可识别符号；梗的发布时间能判断它是投票前背景、投票中动员还是结果后再叙事。
- 阿求的“现实年表会死、官方叙事不让时间推进”矛盾，在2024年形成了可观察的跨平台赛博喜丧话题；第20回跃升、第21回回落符合短期峰值模型。
- 恋恋、芙兰、琪露诺、妖梦的长期名次不能被单一赛后视频解释，更符合原作符号、作品曝光和多年二创累积的慢变量。
- 结果传播与投票结果的分布应同时读：头部差距、票型和计分规则可能改变“谁第一”的标题，而社媒热度往往在结果公布后才达到峰值。

### 不能下

- 不能写“阿求一设导致第20回上升47名”，也不能写“阿求于2024-08-07官方死亡”。
- 不能把B站累计播放、X趋势估算、Google指数、支援作品数相加成统一热度分数。
- 不能从单条拉票帖、单个梗视频或结果日庆祝反推新增票数、异常投票或因果效应。
- 不能把一届自愿问卷的低龄比例直接写成“所有东方受众都完成世代交替”。
